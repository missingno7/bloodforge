- Full physical/path/tier inventory and read-only reference/observer/native research.

- Paired XMapEdit renders with input integrity checks, source-object traces and recorded visual limitations.

- Hash-checked cross-tool evidence bundle and append-only distinct validation results.
- Per-step native surface appearance and relative texture-alignment anchors.

- Fitted reconstruction and paired-view CLI commands with indexed source/output lineage.

## Current bottlenecks

1. Construct explicit landings and connecting areas in LevelScene. Current
   source-held-fixed fixtures restore views but do not generate any context.
   Appearance is measured from the source, not selected by a learned grammar.
2. Build a reliable input-and-position runtime harness independent of the
   unfinished autonomous bot. Its inconsistent traces are quarantined as
   diagnostics and must not gate correctness or promotion. Initialization alone
   must not promote playability or step-height bounds.
3. Extend independent geometry checks and add actual collision/clearance evidence.
   The current 8192-Z threshold is a labelled heuristic.
4. Decode typed Blood extensions and build one tutorial-backed door/lift network;
   require activation and interaction evidence before promotion.
5. Learn more than bounds: synthesize constrained compositions of trusted
   primitives, with counterexamples and held-out structural/visual/runtime tests.

## Intentionally not claimed

No verified recipe, full original playable level, functional door/lift, complete
X-record semantics, general room compiler, automatic code synthesis, general
visual generalization, objective tier quality, or perfect author/revision leakage
prevention. Future work starts from these recorded limitations rather than
relabeling partial checks as success.
