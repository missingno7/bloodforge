# Living task ledger

## Demonstrated

- Independent Git repository and Python package; no llmapper imports or copied game assets.
- Full physical/path/tier inventory and read-only reference/observer/native research.
- Versioned knowledge/workspace databases, FTS retrieval, content-addressed outputs.
- Complete deterministic ingestion with error isolation, incremental reuse and checkpoints.
- v7 parser/writer with opaque extension preservation and real campaign round trips.
- Strict staircase discovery on campaign, community and tutorial populations.
- Training-domain inference, revision-group split and frozen held-out benchmark.
- Semantic stair scenes, deterministic compiler, preconditioned transactions and undo.
- Independent polygon/Z/portal/material comparison and separate validation dimensions.
- Paired XMapEdit renders with input integrity checks, source-object traces and recorded visual limitations.
- NBlood initialization smoke with private asset staging and before/after input hashes; no traversal claim.
- Hash-checked cross-tool evidence bundle and append-only distinct validation results.

## Current bottlenecks

1. Preserve context at fragment boundaries and surface materials/shading/panning.
   A matched-geometry reconstruction currently loses the source room at the
   midpoint camera. Pin these two renderer poses as visual regression evidence.
2. Add NBlood traversal assertions with controlled input and observable player
   positions. Initialization alone must not promote playability or step-height
   bounds. Keep runtime/environment failures separate from construction failures.
3. Extend independent geometry checks and add actual collision/clearance evidence.
   The current 8192-Z threshold is a labelled heuristic.
4. Decode typed Blood extensions and build one tutorial-backed door/lift network;
   require activation and interaction evidence before promotion.
5. Learn more than bounds: synthesize constrained compositions of trusted
   primitives, with counterexamples and held-out structural/visual/runtime tests.

## Intentionally not claimed

No verified recipe, full original playable level, functional door/lift, complete
X-record semantics, general room compiler, automatic code synthesis, rendered
fidelity pass, objective tier quality, or perfect author/revision leakage
prevention. Future work starts from these recorded limitations rather than
relabeling partial checks as success.
